Два критичных нюанса

В .env стоит устаревшее имя модели

Репо free-claude-code в .env.example указывает deepseek-chat — DeepSeek её переименовал. Если не поменять — будет ConnectionRefused при запуске. В нашем промпте установки эта инструкция уже зашита, Claude сам пропишет актуальное имя (deepseek-v4-pro).

Промо со скидкой ×100 закончилось 5 мая 2026

До 5 мая разница доходила до ×3000 в пике (с кэшем + Flash). Сейчас стабильно ×30 раз дешевле Claude Opus. Всё равно копейки — но не магия трёх тысяч.

Пошаговая инструкция

Десять шагов

01/10

Регистрация на DeepSeek и API-ключ

Получаем ключ доступа для подключения к нейросети.

Заходишь на platform.deepseek.com
Регистрируешься через почту или Google
Пополняешь баланс на $5 (этого хватит надолго)
В левом меню → раздел API Keys
Жмёшь Create new API key, даёшь любое имя
Копируешь ключ сразу — он показывается ОДИН РАЗ
Сохрани ключ в отдельной заметке. Никому не показывай и никогда не вставляй в чат с DeepSeek боевые ключи / пароли.
02/10

Клонируем прокси и подключаем DeepSeek

Прокси-роутер free-claude-code перехватывает запросы Claude Code и перенаправляет их в DeepSeek.

Открываешь Antigravity
Создаёшь новую папку под проект (например D:\DEEPSEEK) и открываешь через File → Open Folder
Открываешь терминал: Terminal → New Terminal
Запускаешь Claude Code: claude и Enter
Когда Claude Code загрузился — вставляешь промпт ниже (замени [ВСТАВИТЬ КЛЮЧ] на свой)
Промпт #1 — Установка прокси
Клонируй этот GitHub-репозиторий в текущую папку: https://github.com/Alishahryar1/free-claude-code Прочитай README, выполни все шаги установки и настройки прокси. Подключи его к DeepSeek API с моим ключом: [ВСТАВИТЬ КЛЮЧ] ВАЖНО — про модель: репо в .env.example указывает "deepseek-chat", но DeepSeek её переименовал. Перед запуском прокси сходи в API DeepSeek, узнай актуальное имя (скорее всего deepseek-v4-pro), пропиши его в .env. Создай два шорткат-алиаса в PowerShell-профиле: - ds — Claude Code через прокси - ds-yolo — то же + --dangerously-skip-permissions Запусти ds, проверь что работает без ConnectionRefused.
Если Antigravity для тебя новое — глянь отдельный гайд по нему. С нуля до уверенной работы.
Claude всё сделает сам: клонирует репо, поставит зависимости, запишет ключ в .env, создаст алиасы ds и ds-yolo. Занимает 2-3 минуты.

Запускаем DeepSeek в новом терминале

Проверяем что прокси работает и под капотом реально DeepSeek.

Стартует интерфейс Claude Code — но под капотом DeepSeek V4 Pro

Спрашиваешь напрямую — убедиться что движок правильный
Промпт #2 — Подтверждение модели
Подтверди что мы работаем через DeepSeek V4 Pro.
Если спросить «кто ты» — ответит «Claude Sonnet 4.6». Это нормально, system prompt подменяется. Но под капотом реально DeepSeek.

Тестируем Tool Use на кастомном скилле

Главная фишка прокси — DeepSeek умеет дёргать кастомные скиллы Claude Code как родной. Раньше сторонние модели на этом сыпались.

Идёшь в DS-терминал
Вызываешь любой свой кастомный скилл
Промпт #3 — Тест скилла
/content
Если у тебя нет своего скилла — попроси DS создать файл, выполнить bash-команду, или дёрнуть WebFetch. Главное — проверить что инструменты дёргаются корректно.

awesome-design-md — пакет с дизайн-системами Apple, SpaceX, Tesla, Linear, Vercel и других.

В DS-терминале даёшь промпт ниже

Промпт #5 — Сайт в стиле SpaceX
Используя дизайн-репо awesome-design-md в этой папке, возьми дизайн-систему SpaceX и собери красивый одностраничный лендинг для рок-группы МАСТОДОНТ. Также используй компоненты из этого репо: https://github.com/shadcn-ui/ui И добавь вторым блоком на сайте калькулятор «Сколько энергии у тебя на сцене» — пусть будет интерактивно и круто.

DeepSeek дописывает сложный калькулятор

Сложная математика и логика — не дизайн. Отдаём DeepSeek (в 30 раз дешевле, идеально для алгоритмов).

Идёшь в DS-терминал
Чистишь контекст командой /clear
Запускаешь сайт локально: npm run dev (откроется localhost:3000)
Даёшь промпт ниже, скармливая URL текущего сайта — DS подхватит стиль
Промпт #6 — Сложный калькулятор
Я хочу добавить на сайт второй калькулятор — «Доход с тура» (ROI рок-карьеры). Сложный, с переменными: — количество концертов в туре — средняя вместимость зала — цена билета — процент заполняемости — расходы на тур (логистика, отель, еда) Сделай его настолько сложным и умным, насколько возможно. Поставь третьим блоком, ПОД калькулятором энергии. Вот ссылка на текущий HTML, чтобы ты вписался в стиль 1в1: http://localhost:3000
DeepSeek сам подхватит эстетику сайта (шрифты, цвета, glow), и допишет калькулятор будто это делал тот же дизайнер. Сессия стоит меньше доллара.
